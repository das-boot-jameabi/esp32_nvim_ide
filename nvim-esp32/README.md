# توسعهٔ ESP32 با Neovim و PlatformIO

این مجموعه، تنظیم بدون افزونهٔ [init.lua](init.lua) را توضیح می‌دهد. رابط LSP و تکمیل کد از امکانات داخلی Neovim هستند؛ clangd تحلیل C/C++ را انجام می‌دهد و PlatformIO مسئول ساخت و ارتباط با برد است.

| راهنما | محتوا |
|---|---|
| [راه‌اندازی](setup.fa.md) | نصب پیش‌نیازها، فعال‌کردن تنظیم، ساخت اطلاعات کامپایل و عیب‌یابی |
| [استفادهٔ روزمره](usage.fa.md) | حالت‌های Vim، میان‌برها، ساخت، آپلود، سریال و جابه‌جایی بین فایل‌ها |
| [شرح فنی init.lua](init-explained.fa.md) | توضیح بخش‌به‌بخش کد، چرخهٔ LSP و اجرای فرمان‌های PlatformIO |

این راهنماها برای ویندوز و پروژه‌های PlatformIO با Arduino یا ESP-IDF نوشته شده‌اند. کد firmware در این مخزن توزیع نمی‌شود؛ هر پروژه مخزن مستقل خود را دارد.

```text
D:/Programming/esp32-blink/     ← پروژهٔ مستقل Arduino
D:/Programming/esp32-sensor/    ← پروژهٔ مستقل ESP-IDF
```

در هر پروژه، پوشهٔ حاوی `platformio.ini` ریشهٔ پروژه است. برای هر کدام باید اطلاعات کامپایل جداگانه تولید شود.

فایل داخل این پوشه نسخهٔ آمادهٔ تنظیم است. Neovim معمولاً نسخهٔ موجود در `stdpath('config')` را اجرا می‌کند؛ ویرایش این نسخه به‌تنهایی تنظیم فعال را تغییر نمی‌دهد، مگر آنکه با گزینهٔ `-u` اجرا شود.
